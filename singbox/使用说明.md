# sing-box 配置与规则

入口配置位于仓库根目录的 [singbox.json](../singbox.json)。本目录包含由 `clash/` 转换的 12 份 JSON 源规则，名称一一对应，保留匹配顺序和原有规则内容（包括源文件的重复条目）。这是一份转换快照；后续修改 Clash 规则不会自动同步。

## 使用

1. 使用 sing-box **1.14.x** 或支持相应字段的客户端。本配置已用 **1.14.4** 的 `sing-box check` 检查；更旧内核可能不支持 `http_client` 等字段。
2. 下载根目录的 `singbox.json`，在本地修改 5 个 `type: vless` 的节点：填写 `server`、`server_port`、`uuid` 和 `tls.server_name`。这些节点均使用不可连接的占位地址和 UUID，不要把真实参数提交到公开仓库。
3. 普通节点模板为 VLESS + TCP + TLS，启用 Chrome uTLS 指纹。若服务器使用 Reality，在对应节点的 `tls` 内增加 `"reality": {"enabled": true, "public_key": "实际公钥", "short_id": "实际短 ID"}`；仅当服务端要求 Vision 时，在节点顶层加入 `"flow": "xtls-rprx-vision"`。若为 WebSocket/gRPC，须按实际配置增加 `transport`，不要套用 TCP 模板。
4. 本地混合代理监听 `127.0.0.1:7890`；需要自行开启系统代理或让应用使用该端口。与 Clash 同时运行时，请避免端口冲突。
5. 配置提供本地 Clash API `127.0.0.1:9090`，可用兼容面板或客户端界面选择分组；未附带网页面板。缓存会保存选择和 FakeIP 信息。

## 分组

- `SGP`、`SJC`、`GEN2`、`FRA`、`reflect` 各自指向同名的 `-Node` 节点。
- `Proxy` 保留为通用分组。与当前 `clash.yaml` 一致，在尚未添加通用节点时，里面只有 `DIRECT`。sing-box 此处没有照搬 Clash 的 `include-all`；新增通用出站后，须手动将其 tag 加入 `Proxy.outbounds`。
- AI、AppleProxy、Apple、YouTube、Video、Google、Meta、USHome、UltraMobile、Surfing 和 Final 可独立选择 `Proxy` 或上述 5 个分组，Apple 默认 DIRECT，其余默认 Proxy。
- `antiad` 的唯一选项为 `REJECT`（block 出站），现有 RejectRule 命中后进入该组；没有额外增加广告库。

## DNS 与国内分流

- DNS 入口为 `127.0.0.1:1053`，同时支持 TCP / UDP；它通过路由动作交给内置 DNS 处理。
- 国内 DNS 使用 AliDNS DoH，节点服务器域名使用该直连解析器，避免解析依赖节点自身。公共 DoH 的域名由 `223.5.5.5` 引导解析。
- 非国内 DNS 默认使用 Cloudflare DoH，通过 `Proxy` 出站；Google DoH 和 DNSPod DoH 保留为可切换的备用定义，**不是自动故障切换**。如需使用备用，在对应规则及解析器引用中切换 server tag。
- 当前 Proxy 只有 DIRECT，因此国外 DoH 暂时直连。如果所处网络无法直连国外 DoH，请在本地给 Proxy 添加可用节点/分组选项并选中，或把国外 DNS 的 detour 改为已经配置好的专属分组。
- 从本地 DNS 入口发起的非国内 A 查询使用 FakeIP；AAAA 查询返回空结果。域名分流优先，随后进行 IPv4 解析和国内 IP 兜底匹配，未命中规则走 Final。
- `geosite-cn` 和 `geoip-cn` 使用 SagerNet 的远程 `.srs` 规则，每天更新。这里没有直接引用 Clash 的 `geosite.dat` / MMDB 文件。
- 12 份自定义规则通过本仓库 `singbox/*.json` 的原始链接加载，每天更新；规则下载使用 DIRECT。首次运行需能访问 GitHub 原始链接，失败时请检查网络或在本地调整规则的 `http_client.detour`。

## TUN

与当前 `clash.yaml` 的 `tun.enable: false` 对应，默认没有启用 TUN。需要全局接管时，可在支持的客户端管理 TUN，或向 inbounds 数组中加入：

```json
{
  "type": "tun",
  "tag": "tun-in",
  "address": ["172.19.0.1/30"],
  "mtu": 1500,
  "auto_route": true,
  "strict_route": true,
  "stack": "mixed"
}
```

启用 TUN 通常需要系统权限。配置已包含 DNS 劫持规则和自动检测出站网卡。

## 校验

配置通过 sing-box 1.14.4 的 `check`；12 份 JSON 规则均已用同版本内核成功编译，并抽查通配域名、普通域名和 IP 匹配。没有使用真实节点进行连通性测试。
